# التخطي AI Studio — الإصدار النهائي V15

منصة عربية RTL مستقلة، متجاوبة مع الجوال والكمبيوتر، وتعمل كواجهة ثابتة دون خطوة بناء. تتضمن دليل الأدوات، البحث والتصنيفات والمفضلة، قوالب الأوامر، مسارات العمل، لوحة المهام المحلية، وموصلًا اختياريًا لتوليد النصوص عبر Worker.

## الملفات

- `public/`: الموقع الثابت الجاهز للرفع إلى الاستضافة، ويحتوي `index.html` وملفات PWA والخصوصية ورؤوس الحماية.
- `worker/index.js`: خادم Cloudflare Worker اختياري لتوليد النصوص عبر OpenAI Responses API أو Google Gemini API.
- `wrangler.toml`: إعداد نشر Worker.
- `netlify.toml`, `vercel.json`, `render.yaml`: إعدادات استضافة الواجهة على منصات مختلفة.
- `.github/workflows/pages.yml`: نشر الواجهة على GitHub Pages عند رفع الملفات إلى مستودعك وتفعيل Pages.

## أسرع طريقة لنشر الواجهة

### Cloudflare Pages (رفع مباشر)
1. افتح Cloudflare Dashboard ثم Workers & Pages ثم Create ثم Pages.
2. اختر Direct Upload / Upload assets بحسب الخيارات الظاهرة في حسابك.
3. ارفع محتويات مجلد `public` (وليس مجلد المشروع كاملًا).
4. بعد النشر، افتح رابط `pages.dev` الناتج واختبر الواجهة على الهاتف والكمبيوتر.
5. لإضافة نطاق مخصص، اربطه من إعدادات المشروع. لا توجد حاجة إلى مفاتيح API لتشغيل دليل الأدوات محليًا أو تصفح الروابط.

### Netlify
1. ارفع مجلد المشروع إلى مستودع Git، أو استخدم رفع المجلد `public` عبر أداة النشر اليدوي المتاحة في حسابك.
2. إن استخدمت ربط Git، اجعل Publish directory هو `public` وBuild command هو `echo 'no build step'`.
3. ملف `netlify.toml` يتضمن إعدادات الرؤوس الأمنية الأساسية.

### Vercel أو Render أو GitHub Pages
- Vercel: ارفع المستودع إلى حسابك، وسيقرأ `vercel.json` إعدادات الرؤوس.
- Render: اربط مستودع Git يحتوي هذا المشروع، واختر Blueprint من `render.yaml` أو أنشئ Static Site وانشر `public`.
- GitHub Pages: ارفع المشروع إلى مستودعك مع مجلد `.github/workflows`، ثم فعّل Pages عبر GitHub Actions. يجب أن يكون المشروع في جذر المستودع أو عدّل مسار workflow.

## تفعيل توليد النصوص عبر API (اختياري)

الواجهة تعمل دون API. التوليد الحي يتطلب Worker منشورًا ومفتاحًا صالحًا لدى المزود، وقد يستهلك رصيدًا مدفوعًا.

1. ثبّت Node.js ثم داخل مجلد المشروع نفّذ `npm install`.
2. عدّل `ALLOWED_ORIGINS` في `wrangler.toml` ليحتوي أصل موقعك الفعلي فقط، مثل `https://your-project.pages.dev`. لا تستخدم `*` في الإنتاج.
3. سجّل دخولك إلى Cloudflare عبر `npx wrangler login`.
4. أنشئ رمز وصول قويًا خاصًا بمساحة الاستخدام، ثم نفّذ `npx wrangler secret put APP_TOKEN` وأدخل الرمز. لا تحفظه في Git أو ملفات عامة.
5. أضف واحدًا أو كليهما: `npx wrangler secret put OPENAI_API_KEY` و/أو `npx wrangler secret put GEMINI_API_KEY`.
6. انشر Worker باستخدام `npx wrangler deploy --config wrangler.toml`.
7. في الواجهة، أدخل عنوان Worker ورمز `APP_TOKEN` في قسم التكاملات ثم اختبر الاتصال.

### تحذير أمني مهم

طريقة `APP_TOKEN` مناسبة لتجربة شخصية أو مساحة خاصة محدودة. إذا كان الموقع عامًا ويستخدمه زوار متعددون، فإن إدخال رمز مشترك في المتصفح لا يوفر مصادقة إنتاجية للمستخدمين؛ قد يتمكن أي شخص يحصل على الرمز من استهلاك رصيد API. **لا تطلق توليدًا مدفوعًا للعامة بهذه البنية وحدها.** قبل ذلك أضف مصادقة مستخدمين فعلية، حصص استخدام لكل حساب، تحديد معدل على مستوى الخادم، مراقبة الإنفاق، وسياسة خصوصية وشروط استخدام مناسبة. لا تُضمّن مفاتيح المزود في HTML أو JavaScript.

## التخزين والخصوصية

- المفضلة والمهام محفوظة محليًا في المتصفح، ولا توجد قاعدة بيانات أو مزامنة حسابات في هذه النسخة.
- يمكن حذف بيانات الموقع من إعدادات المتصفح؛ صدّر نسخة احتياطية قبل مسحها إذا احتجت الاحتفاظ بها.
- عند استخدام التوليد الحي، يرسل المتصفح النص إلى Worker ثم إلى مزود النموذج المحدد. راجع شروط ذلك المزود قبل إرسال معلومات خاصة.
- لا تُرسل كلمات مرور أو بيانات مالية أو معلومات حساسة.

- [ ] إضافة مفضلة، إعادة تحميل الصفحة والتأكد من بقائها.
- [ ] إنشاء مهمة وتغيير حالتها ثم تصدير ملف JSON.
- [ ] تجربة الواجهة على عرض هاتف وعلى سطح المكتب.
- [ ] التأكد من فتح `/privacy.html` و`/404.html`.
- [ ] إن فُعّل Worker: اختبار `/health` ثم توليد طلب قصير، ومراجعة سجلات المزود وحدود الإنفاق.
- [ ] التحقق من عدم وجود أسرار API في ملفات الموقع أو مستودع Git.

## حدود معروفة

- لا ينشئ الموقع تلقائيًا صورًا أو فيديو أو موسيقى؛ يوفر أوامر وروابط، بينما التوليد النصي عبر API اختياري.
- لا ينشر المحتوى تلقائيًا على الشبكات الاجتماعية.
- قائمة الأدوات ليست حصرًا لكل الخدمات، وقد تتغير الروابط والميزات والأسعار وشروط الاستخدام.
- لم يتم نشر هذه الحزمة إلى حساب استضافة المستخدم أو اختبار API حي بمفاتيح حقيقية أثناء إعدادها.
