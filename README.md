# تخطي AI Studio

مساحة عربية للعمل الذكي تجمع روابط أدوات الذكاء الاصطناعي، منشئ أوامر، ولوحة مهام محلية.

## الروابط

- الموقع المنشور: https://takhti-ai-studio.onrender.com
- المستودع: https://github.com/azoz455/takhti-ai-studio
- لوحة الاستضافة: https://dashboard.render.com/static/srv-dbb26u0n74is73c08ngg

## الحالة الحالية

- الواجهة الثابتة منشورة على Render.
- النشر التلقائي مفعّل عند تحديث فرع `main`.
- أدوات الواجهة تفتح مواقعها الخارجية، ومنشئ الأوامر يعمل محليًا.
- لوحة المهام تحفظ بياناتها في المتصفح نفسه، وليست قاعدة بيانات سحابية.
- لم تُضف مفاتيح API أو خدمة خلفية إلى الاستضافة؛ لا تضع مفاتيح سرية في ملفات الواجهة.

## استعادة حزمة V15 الكاملة

توجد حزمة المصدر `takhti-ai-studio-v15-final.zip` في جذر المستودع. لنسخ جميع ملفات المصدر إلى الجذر، افتح تبويب **Actions** في GitHub، اختر **Restore complete Takhti AI Studio source**، ثم **Run workflow** على فرع `main`. يقوم سير العمل بفك الحزمة وإضافة ملفات المصدر الكاملة إلى المستودع. عندها يُفترض أن يبدأ Render نشرًا تلقائيًا جديدًا.

إذا لم يظهر سير العمل أو لم يبدأ، تحقق من أن GitHub Actions مفعّلة للمستودع.

## النشر

إعداد Render الحالي:
- النوع: Static Site
- الفرع: `main`
- مجلد النشر: `public`
- أمر البناء: `echo 'Takhti AI Studio static site ready'`

## الخصوصية والأمان

لا توجد مصادقة مستخدمين أو قاعدة بيانات سحابية في الواجهة الحالية. لا تُدخل بيانات حساسة. راجع صفحة الخصوصية المنشورة قبل توسيع الخدمة إلى مستخدمين آخرين.
